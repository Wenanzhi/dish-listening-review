# Data and decoder attribution

The application source is MIT licensed. This does not relicense the benchmark.

- **DiSH-Bench exhibition V3**: [dataset](https://huggingface.co/datasets/Heiheihaha17/DiSH-Bench-exhibition-v3), frozen data revision `87e9f4d5394887d5d8a262ae8497ff2ba0089627`. Metadata, prompts, reference answers and scene bindings are derived from this revision. The dataset is a composite release with [component-specific terms](https://huggingface.co/datasets/Heiheihaha17/DiSH-Bench-exhibition-v3/blob/87e9f4d5394887d5d8a262ae8497ff2ba0089627/LICENSES.md).
- **Source speech**: LibriSpeech, Vassil Panayotov, Guoguo Chen, Daniel Povey and Sanjeev Khudanpur, *LibriSpeech: An ASR corpus based on public domain audio books*, ICASSP 2015. [Original corpus](https://www.openslr.org/12/) and [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The local FLAC assets are lossless PCM16 crops; exact original corpus path, original SHA-256, crop sample indices, source license and derived hash are recorded per event in `web/data/references/`. No gain or time stretching was applied to these crops. They are dry source segments, not isolated reverberant receiver stems.
- **Mixtures and noise**: mixture audio is fetched from the immutable public dataset revision, not relabeled MIT. Environmental sounds retain per-source attribution and licensing in the dataset's `source_attributions.json` and reproduction archive. Some are restricted to noncommercial use. Consult those records before reusing audio.
- **Binaural decoder**: KEMAR dummy-head HRIR measurements by **Bill Gardner and Keith Martin, MIT Media Laboratory, 1994**. [Original measurements and terms](https://sound.media.mit.edu/resources/KEMAR.html) allow use with author citation. [SOFA distribution](https://sofacoustics.org/data/sofatoolbox_test/MIT_KEMAR_normal_pinna.sofa), SHA-256 `647cebf09bd0ed5fca359c071d888779325a5c3376669b120029df817e7ea2bd`. `web/assets/decoder.json` contains a derived first-order regularized FIR projection. Method, orientation, source URL and attribution are embedded in the file. This follows the DiSH project's `dynamic_demo/binaural.py` method; it is not the IEM MagLS decoder.

**UI font**: a locally served, renamed glyph subset of [Noto Sans CJK SC](https://github.com/notofonts/noto-cjk), under the SIL Open Font License 1.1. Copyright and license are retained in `web/assets/fonts/OFL.txt` and the font metadata. `scripts/subset_font.py` reproduces the subset from the upstream OTF.

The user interface uses no third-party hosted fonts, analytics, or runtime packages.
